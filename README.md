# NoWarden

**NoWarden** is an ultra-lightweight Paper plugin that completely stops **Warden spawns** and disables the **Darkness effect** across your Minecraft server.

Ideal for SMPs, custom survival servers, or mini-games where players want to explore Deep Dark structures without dealing with Wardens or blinded vision!

---

### Features

 **Block Warden Spawns:** Automatically cancels Warden spawns triggered by Sculk Shriekers or entity events.
 **Disable Darkness Effect:** Blocks the Darkness potion effect from being applied to players.
 **Zero Lag:** Highly optimized event handling with zero impact on server performance or TPS.
 **Plug & Play:** Works out of the box — no config required.
